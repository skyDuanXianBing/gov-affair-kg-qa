## 一、任务概述

对灌图阶段入库的 1,306,907 个政务文档块（`documents_chunks.csv`，17.4GB，覆盖 48.2 万政务服务事项）进行 LLM 结构化命题抽取，将非结构化文本转化为可检索、可推理的结构化命题知识，作为图谱的命题层补充。

**技术路线**：SynthKG（受控谓词）+ SocraticKG（命题化、去语境化陈述）
**模型**：qwen3.8-27b（内网服务 http://10.130.71.10:30799，关闭思考链）
**并发**：32
**Prompt 版本**：pilot-v1（受控谓词全集 + 六类条件类型）

```csv

service_id:     65d1d03adcaae0db73e529c32960a352
doc_id:         service:65d1d03adcaae0db73e529c32960a352
source_field:   condition
predicate:      适用对象
condition_type: 适用对象
object_value:   事业法人,社会组织法人
statement:      高等职业学校撤销事项的适用对象为事业法人和社会组织法人。
```

**入库形态**：`Proposition` 节点（8 列全属性），连两条边：
- `(GovernmentService)-[:statesProposition]->(Proposition)`
- `(Proposition)-[:extractedFrom]->(Chunk)`

## 五、质量审查结论

### 抽样审查（25 条随机样本 + 5,824 条缺陷扫描）

| 维度 | 结果 |
|---|---|
| statement 完整自洽、去语境化 | 22/25 合格；3 条轻微指代残留 |
| predicate 归类准确 | 23/25 准确 |
| object_value 简洁一致 | 19/25 简洁；6 条整段复制（>80 字） |
| 幻觉检查 | 未发现无中生有 |

### 缺陷模式（抽样 5,824 条）

| 缺陷 | 占比 | 处理建议 |
|---|---|---|
| object_value 过长（>50 字） | 15.7% | 入库时保留 statement、object_value 可截断或留空 |
| 未去语境化指代（"该事项"等） | 2.5% | 可接受，statement 本身仍可读 |
| statement 疑截断 | 1.3% | 占比极低，入库后可过滤 |
| 脏数据（predicate 非法/None） | 0.002%（326 条） | 入库前丢弃 |

### 质量等级：**良**（可入库，需先清洗）

## 六、已知问题与后续工作

### 6.1 师兄反馈：schema 覆盖率问题

**反馈**：六类条件（资格/数量/时间/禁止/例外/适用对象）覆盖率太低。

**核查结果**：六类本身覆盖没问题（84.6%），但条件类文本中确实有 **15.4%（31.1 万条）被归入"其他"**，主要是三类客观存在但 schema 未覆盖的条件：
1. **材料形式要求**（"材料齐全且符合法定形式"）
2. **援引性条件**（"按某某条例第 X 条规定执行"）
3. **程序性前提**（"需先处理好 XX 事务"）

**建议**：schema 从 6 类扩到 9 类（新增上述 3 类），或对现有"其他"做一次轻量重分类（无需重跑全量抽取）。

### 6.2 数据污染（双栈事故）

09-12~09-18 期间因操作失误导致两套抽取栈并行（64 并发打同一批块），产生：
- state 重复标记 29.2 万条（已去重，不影响最终覆盖率）
- CSV 完全相同重复行约 3.5 万条（**入库前必须按整行去重**）

### 6.3 下一步：入库

待执行：
1. CSV 清洗（去重 + 丢弃脏数据）
2. 建 Proposition 节点（schema 已就绪：14 个节点属性）
3. 建边：`(GovernmentService)-[:statesProposition]->(Proposition)`、`(Proposition)-[:extractedFrom]->(Chunk)`
4. 命题向量回填（可选，用于语义检索）
5. QA 系统集成（检索时混合召回命题节点）
