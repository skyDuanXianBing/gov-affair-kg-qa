5. 抽验：至少 2 个事项 cypher 展开，与 csv_v2 原始行比对；**至少 1 个事项带 citeLegal 关联**（v0.2 新增能力，v0.1 图中不存在）。

## 4. 验收标准

- V1：清空后 Neo4j govaffair 库为 0 节点/0 边（含 `_name_vector` 等属性一并清除）。
- V2：indexer 全部文件 0 failures（同 v0.1 判定标准）。
- V3：cypher 实测节点/边合计与各类型计数 == adapter_stats.json 期望值（100% 一致）。
- V4：抽验事项展开内容与 csv_v2 行一致；至少 1 个事项 `citeLegal` 一跳返回 LegalCitation（该能力 v0.1 不存在，必须现验）。

## 5. 风险

- **长任务**（60~90 分钟）：bash 命令设足够 timeout；若被中断，凭 ckpt 恢复续跑，不重头再来。
- **清空不可逆**：v0.1 图已授权删除（可经 csv 重建）；清空前记录计数留档。
- Neo4j 与 OpenSPG server 的会话：清空操作与灌图期间保持 server 可用（容器已在跑，勿重启）。
- 对账口径：以 adapter_stats.json 为唯一权威；csv 行数（文件行数-1）仅作参考，若与 stats 不符以 stats 为准并说明。
